# The published checksum for the ClipScrub app disk image.
#
# The app around this engine is closed source, so its disk image is built and Developer ID signed
# on a maintainer machine rather than in CI here. That means it cannot carry a build provenance
# attestation the way the `clipscrub` CLI does. This file is the answer instead: download the disk
# image from clipscrub.com, hash it, and check it against the line below.
#
#     shasum -a 256 ClipScrub.dmg
#
# One data line, always, in this shape:
#
#     ClipScrub.dmg  version=<marketing>  build=<number>  sha256=<64 lower-case hex>
#
# It is rewritten every time a disk image is uploaded, so it describes the download that was live
# at this commit, which is not necessarily the one you have. A release repeats the line as it stood
# when that release was cut. clipscrub.com always shows the current one.
